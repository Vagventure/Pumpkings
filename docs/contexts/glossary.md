# Glossary

- Trash: A spawned cleanup object with a type, pollution score, income value, pickup time, collider, layer, and optional audio.
- Trash Type: A category used for trash matching, bonuses, and auto-collection.
- Player Character: The 3D controllable character that moves through the scene by point-and-click navigation.
- Walkable Ground: Scene geometry that can receive movement clicks and be sampled onto the NavMesh.
- Point-And-Click Navigation: The movement style where clicking walkable ground sends the player character to that destination.
- Player Animation: The character animation state used to communicate locomotion and cleanup interaction. The current prototype uses `Idle`, `Walk`, and `SS_CrouchIdle` for trash pickup.
- Current Pollution: The current pressure on the level. It increases when trash spawns and decreases when trash is removed.
- Max Pollution: The current-pollution threshold used by `GameManager` for the loss condition.
- Budget: Spendable currency. It increases from cleanup and decreases from purchases.
- Gold Gathered: Gross lifetime budget income earned from removing trash during the current run. It does not decrease when budget is spent.
- Awareness: Progress created by shop purchases and passive awareness bonuses.
- Threat Produced: Gross lifetime pollution/threat generated by trash spawns during the current run. It uses post-bonus pollution values and does not decrease when trash is removed.
- Reward Item: A reward target with its own display text for detail views, such as a bonus or shop item.
- Bonus: A reward that changes future rules, such as cost, awareness, trash pollution, trash income, auto-collection, or passive awareness.
- Shop Item: A purchasable active skill that has display text, budget cost, awareness value, and purchase behavior.
- Reward Item View: The single prefab UI view used to display shop items and card-style reward item surfaces.
- Active Bonus Slot View: The compact HUD view used to display active bonuses with an effect icon, short value, and optional radial cooldown.
- Event Definition: ScriptableObject content used by event presentation.
- Progress Event: A threshold-triggered milestone that can show dialogue through the assigned event presentation resolver, offer reward choices, both, or neither.
- Progress Tracker: Runtime owner of total awareness, total gold gathered, total threat produced, and progress threshold detection.
- Dialogue Panel: The scene-level event UI controlled by one `EventPresentationResolver`.
- Dialogue Line: One runtime-rendered NPC or player message using `DialogueLineView`.
- Dialogue Choice: A selectable player answer configured on `ProgressEventDefinition.dialogueChoices`.
- Choice Label: The short button text for a dialogue choice.
- Player Line: The full player response text spawned after selecting a dialogue choice.

## Vocabulary To Prefer

- Use `player character` for the controllable 3D character.
- Use `point-and-click navigation` for ground-click movement.
- Use `walkable ground` for valid movement click surfaces.
- Use `trash pickup` for the full cleanup interaction: click trash, approach it, crouch for the trash's pickup time, then collect it.
- Use `progress event` instead of `tier` for threshold-triggered event/reward moments.
- Use `dialogue panel` for the scene-level event controller UI.
- Use `dialogue line` for the NPC/player line prefab instance.
- Use `choice label` for the short selectable button text.
- Use `player line` for the full player response shown after selection.
- Use `gold gathered` for gross earned gold.
- Use `budget` for spendable current currency.
- Use `threat produced` for cumulative generated pollution/threat.
- Use `current pollution` for the value that can rise, fall, and trigger loss.
